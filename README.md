# httpchat (formerly javaidkwhattoputherehttp)

## Overview

This project was supposed to be a basic java things like website. But I decided I want to be different. So I coded a whole CLI messaging app in Zig and wrote everything myself with only std library. This includes the printing, the taking input, client, server and everything. I mostly refer to CS:APP as the architecture reference but if im stuck I admit i use claude to help me understand/debug but THERE ARE NO CLAUDE CODE IN MY CODE everything is written by hand. Meaning its ALL ME.

## Tech Stack

- Zig
- Soul from the underworld

## How it was made

Initially, I got bored of python. Then I decided to move to java. Then I also decided Java is boring. Then I was like "damn i should really do something" then that is when the idea of chatting cli app on http protocol goes in my mind. I manage my own memory and thats the fun of it. I ran into so much leaks(thats why i use safeallocator), SO much error that I dont even know exist. In the end I did it finally.
